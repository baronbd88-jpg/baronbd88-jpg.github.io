What the app accesses

Kittintuc uses Google OAuth and the YouTube Data API / YouTube Analytics API only for the channel owner's own account, to upload videos to the owner's channel and to read the owner's own channel statistics.

Data storage

The OAuth token and channel statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising. The app does not collect data from any other person.

Google API Services

Kittintuc's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; the owner then deletes the locally stored token.
